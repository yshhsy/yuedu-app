# 阅读 · Yuedu

轻量级电子书阅读器（PWA），对标主流阅读 App 的核心体验。

## 特性

- **导入书籍**：支持 TXT（自动识别 UTF-8/GBK 编码与章节）、EPUB（含封面/插图/目录），可从本地文件或链接导入
- **阅读体验**：纵向连续滚动（上下滑动翻页）、轻点切换工具栏、跨章节无缝加载、进度条与"剩余分钟"预估
- **个性化**：字号 / 行距 / 字体（默认/宋体/黑体/楷体）/ 四套主题（白天/米黄/护眼/夜间）/ 亮度调节
- **记录**：进度自动记忆与续读、书签、划词划线（可删）、每日阅读时长统计
- **离线可用**：PWA 应用壳缓存，断网可读已导入书籍

## 使用

打开 https://yshhsy.github.io/yuedu-app/ 或在手机上"添加到主屏幕"（PWA）。

书籍数据全部保存在浏览器本地（IndexedDB），不上传任何服务器。

## 技术栈

原生 HTML/CSS/JS（无框架无构建），JSZip 解析 EPUB，Service Worker 离线缓存。

## 本地开发

```bash
python3 -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123
```
